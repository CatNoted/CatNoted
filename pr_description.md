💡 What: Optimized the `CommandPalette` component by replacing an O(N) array search (`flatItems.indexOf(cmd)`) inside the rendering loop with an O(1) Map lookup (`flatItemsIndexMap.get(cmd.id)`).
🎯 Why: The `CommandPalette` re-renders frequently (on every keystroke while filtering or arrow-key navigation when changing `selectedIndex`). Using `indexOf` inside the `.map()` loop caused an O(N*M) time complexity bottleneck, resulting in unnecessary CPU overhead and potential lag during rapid UI interactions.
📊 Impact: Eliminates the O(N*M) bottleneck, ensuring that render loop lookups are O(1), significantly reducing CPU overhead during command palette usage.
🔬 Measurement: Verify by typing quickly in the Command Palette or rapidly holding the down arrow key to navigate the list; the interactions will remain consistently smooth without spiking the main thread.
